# StoreShots

Генератор скриншотов для **App Store** и **Google Play** прямо в браузере.
Всё работает на клиенте (Canvas), без сервера — фотки никуда не загружаются.

## Возможности
- Пресеты размеров: App Store (1290×2796, 1242×2688, 5.5", iPad) и Google Play (9:16, 9:19.5, 16:9, планшет, feature graphic)
- Загрузка нескольких скриншотов, у каждого свой **заголовок и подзаголовок** (кнопка «+ Кадр»)
- Рамка телефона (iOS «динамический остров» / Android камера-точка), рисуется на Canvas
- **Наклон телефона** для «живого» стиля сторов
- Фон: сплошной цвет / градиент / своя картинка + готовые **палитры** в один клик
- Настройка шрифта, размера, цвета и положения текста (сверху/снизу)
- Экспорт: PNG по каждому кадру, ZIP текущего размера или **ZIP сразу во все размеры** (папки по устройствам)
- **Сохранение/загрузка проекта** в JSON (со скриншотами) — можно вернуться и доредактировать
- Интерфейс RU / EN

## Публикация на GitHub Pages
1. Создать репозиторий и запушить эти файлы (`index.html` в корне).
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/root`.
3. Открыть выданный URL.

Локально: просто открыть `index.html` в браузере.
